# 五行灵兽 · 交易人格养成测评

> **评委快速通道**：作品介绍与运行说明见 [`项目说明.md`](项目说明.md)；本 README 面向团队协作开发。

PandaAI 苏客松参赛作品。用三关真实历史行情，让用户在 2 分半内做完三次决策，
地上长出三株作物、挂出不同颜色的橡果，灵兽吸走果实的光长大——最后得到一张
「五行 × 灵兽 × 成长形态」的交易人格画像，以及一条针对卡点的练习路径。

> **一句话总纲**：地不变，果由你种；不点地，只做决定——做完了，地上就多一株，长什么样都是你选的。

## 快速开始

### 跑 demo

零依赖，双击 `demo/index.html` 即可（file:// 已验证无报错）。

需要本地服务时（部分浏览器对 `file://` 的 canvas 有限制）：

```bash
node _tools/serve.js      # http://127.0.0.1:8787
```

### 跑数据脚本（需要 PandaData 凭据）

凭据**只走环境变量**，任何文件里都不许出现明文。

```bash
# Windows CMD
set PD_U=你的账号
set PD_P=你的密码

# PowerShell
$env:PD_U="你的账号"; $env:PD_P="你的密码"

# 然后
E:\panda_venv311\Scripts\python.exe test_pandadata.py
```

### 跑单测

```bash
python verify_paths.py     # 五条路径的行为码判定，改权重后必须重跑
python export_stages.py    # 重新导出 data/stages.json
```

## 三条轴，别混淆

| 轴 | 是什么 | 变不变 |
|---|---|---|
| 姿态 / 主色 | 灵兽是谁（五行） | 只看刚才那次决策，**不累积** |
| 显影度 / 阶 | 长到哪一阶（三阶） | **本局累积**，不存档、不跨会话 |
| 果实大小 / 光泽 | 盈亏 / 过程质量 | 大小只有爽感，**光泽才被灵兽吸收** |

## 开发红线（改代码前必读）

1. **田地高度恒定**：`#field` 必须 `flex:none` + 固定高度，`--ground` 用固定像素。
   任何面板折叠/展开都不许改变田地高度，否则植株会按旧高度算，果实飘出地外。
2. **行为在前，痕迹在后**：查了数据土才湿，设了止损才有篱笆。不能先有视觉再有行为。
3. **农事只有回声，没有按钮**：播种/抽芽/结果/取光全部由决策自动触发，不许加浇水按钮或生长计时器。
4. **成长数值只能是过程值**，且不跨会话。一存档就变成账号等级，撞官方红线「收益不能作为能力唯一标准」。
5. **果实大小不进任何评分**：只有光泽（过程质量）进显影度。
6. **株高随仓位连续变化**，不许分档，80% 和 100% 必须看得出差异。
7. **卡点判定必须有证据门**：只看权重形状不够，得同时有行为证据（如「不会验证」需查数据 ≤2 项）。
8. **判定顺序先看有无止损单**：设了止损未触发 = 纪律（金），不是死扛（土）。判反会把守成型和纪律型算错。

## 协作约定

- `main`：可演示、可提交的稳定版。**只接受 PR，不直接推。**
- `dev`：日常开发分支，两人都往这里合。
- 提交前跑一遍 `python verify_paths.py`，五条路径全过再提。
- 中文路径会导致某些工具崩溃，Python/Dart 相关一律确认编码。

### 分支流程

```bash
git checkout -b feat/你的功能     # 从 dev 切
# ……改代码……
git add -A && git commit -m "feat: 做了什么"
git push -u origin feat/你的功能  # 然后在 GitHub 上对 dev 提 PR
```
