# assets/ · 美术资源放这里

当前 demo 全部用 CSS 画的占位图形，这个目录是空的。
图片做好后按下面的文件名丢进来，改一行开关就能显示。

## 1. 打开图片

`demo/app.js` 第 ~800 行：

```js
var BEAST_IMG_ON = false;   // ← 改成 true
```

关着的时候不会发请求（避免 5 个 404 把控制台刷红），走的是同色剪影降级。

## 2. 选兽卡片用的 5 张（潜力态）

| 文件 | 动物 | 对应五行 |
|---|---|---|
| `beast_cheetah_1.png` | 猎豹 | 金 |
| `beast_elephant_1.png` | 大象 | 木 |
| `beast_fox_1.png` | 狐狸 | 水 |
| `beast_wolf_1.png` | 狼 | 火 |
| `beast_turtle_1.png` | 龟 | 土 |

**规格**：正方形、透明背景、主体居中、四周留 8% 安全边。
建议导出 512×512，显示区只有 60×60，缩下来必须一眼认得出。

> 文件名里的 `_1` 是潜力态（幼兽）。成长期 / 定形是 `_2` / `_3`，
> 后面接进关卡和结果页时用得上。

## 3. 生图提示词

见根目录 `生图提示词包v1.0·田园·果实·灵兽.md`。
第 3 节是 5 只灵兽的完整描述，第 3.1 节有三阶差异的统一后缀。

**注意**：提示词里写的动物顺序与这里一致，直接对应。
先在 `assets/` 里只放 1 张试，确认尺寸和透明边没问题，再批量补剩下 4 张。

## 4. 还没接图片的地方

| 位置 | 现在 | 有图之后 |
|---|---|---|
| 选兽卡片 | 剪影 | 换成 `_1` 立绘 |
| 关卡田地里的灵兽 | 剪影（随形态缩放） | 换成 `_1/_2/_3`，按 `data-form` 切换 |
| 结果页的灵兽 | 同上 | 同 |
| 田园背景 | CSS 渐变 | `bg_spring.webp` 等，地平线锁画面 64% |

背景图接入时注意：`#field` 的地面基准是固定像素 `--ground: 26px`，
背景图的地平线必须和它对齐，否则植株会浮在空中或陷进土里。
