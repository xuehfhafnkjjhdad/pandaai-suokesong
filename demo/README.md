# 五行灵兽 · 可运行 demo（v0.2 · 第一版系统 + 秒级节奏）

> 基线：《开发基线 v1.0 · 第一版系统 + 秒级节奏》（`../开发基线v1.0·第一版+秒级节奏.md`）
> 一句话：**第一版的系统全保留，只把"明天再来"改成"2.8 秒之后"。**

三关真实行情（春 / 夏 / 冬）→ 照料 + 一次决策 → 地里长一株 → 关末三株连喂 → 揭卡。

## 怎么看

双击 `index.html` 即可（纯静态，无需服务器、无需联网、无构建）。
手机上看：把整个 `demo` 文件夹丢进微信/网盘，用手机浏览器打开 `index.html` 也行。

## v0.2 相比 v0.1 改了什么

| 项 | v0.1（v2.3 路线） | v0.2（第一版路线） |
|---|---|---|
| 四季 | 删掉 | **回来了**：春（震荡）/ 夏（狂热）/ 冬（深跌），一关一季，0.4s 过渡，零新图 |
| 农事动作 | 只有"查数据" | **浇水 / 松土 / 立篱笆** 三个动作，点完 0.15s 回执，不产生等待 |

| 成长 | 秒级喂养 | **关末 2.8s 三株连喂**，边喂边升级（潜力态 → 成长期 → 定形） |

| 推荐 | 卡点驱动 | **15 格矩阵**（五行 × 形态），卡点决定"先练哪一步" |

| 血脉变体 | 无 | 结果页留位（回访钩子，不实现） |

## 秒级时序（唯一改动）

每关（2.8 秒）：

```
进关 换季 0.4s → 自由照料（每次点 0.15s 回执）
0.0 决策锁死 → 0.2 播种 → 0.5 抽芽(株高=仓位) → 0.9 结果(果色=五行,果大=盈亏)
→ 1.3 揭晓(数字滚动 + K线往后走) → 2.0 灵兽取光 → 2.8 留痕
```

关末（2.8 秒）：三株并排，灵兽依次取光，每颗 0.8s，形态实时升级。

## 已经真的跑通的

- 三关决策 → 揭晓数字（浮盈亏按上一关仓位算）→ 下一关
- 株高随仓位连续变化（0.12 + 0.40 × 仓位，80% 与 100% 看得出差异）
- 果径随盈亏、果色随行为码、光泽随过程、叶态随有无验证、篱笆随有无止损、水痕随浇水次数
- 空仓不结无果之果，只留一个坑（最多三株，数量本身就是画像）
- 田地高度恒定（面板折叠前后 `#field.clientHeight` 不变，实测 279px）
- 三条路径跑出三种结果（见下表），不是永远同一个答案

| 打法 | 主五行 | 形态 | 卡点 |
|---|---|---|---|
| 先查后动 + 立篱笆 + 轻仓 | 金 60.5% | 定形 | 这一局没抓到明显卡点 |
| 零信息重仓三关 | 火 78.9% | 成长期 | 习惯用重仓表态 |
| 三关全空仓、一次水没浇 | 土 100% | 潜力态 | 一次都没下手 |

## 还没做 / 故意没做

- **任务执行与回流**：结果页那个任务只是文案，点不进去，回流（做完 → 地里多一株）没实现。
- **血脉变体**：只有一行钩子文案。
- **辨作物（知识题）**：第一版 4.4 里的 10% 权重通道，demo 未做。
- **美术全是占位**：灵兽是一个 SVG 剪影，植株是三根 div，果实是渐变圆。只用来判断比例和节奏。
- **成长数值不存档**：刷新即清零。这是设计约束——一跨会话就变成账号等级，撞官方红线。
